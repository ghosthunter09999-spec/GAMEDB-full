# GameDB Backend — Full CRUD (Teacher Method)

## CRUD for every form

| Method | Example | Meaning |
|--------|---------|---------|
| POST   | /forms/contact | Create |
| GET    | /forms/contact | Read all |
| GET    | /forms/contact/:id | Read one |
| PUT    | /forms/contact/:id | Update |
| DELETE | /forms/contact/:id | Delete |

Same pattern for: login, signup, newsletter, review, search, feedback, suggest-game, report-bug, comment, rating, premium.

## Run
```bash
cd Backend
npm install
npm start
```
